CONFIRMED GAPS

A. Model input channel count is not checked against saved normalization width.
   Location: src/nova2026/auditory/decoder.py, validate() and design().
   A valid two-channel window was reduced to one column while retaining its
   metadata. score() accepted it because subtraction/division broadcast it into
   two columns. Scores were [0.9995124826613148, 0.02934030024547265].
   This is an API guardrail defect, not evidence the ordinary RunProcessor emits
   such malformed windows. Reject wrong channel counts before normalization.

B. Recorded playback stops on an EEG processing failure.
   Location: scripts/auditory/streamer.py, stream(), finally block.
   A fake audio worker and injected ReplayFailure reproduced immediate stop-event
   signaling and exception propagation. Offline replay() instead continues mixing.
   Document current behavior; if continuity is required, transport invalid evidence
   and let playback complete in neutral rather than stopping it on recoverable
   EEG-only failure. This probe used no audio device.

C. Held-out checks apply to CLI evaluation, not the replay() callable.
   Location: scripts/auditory/replay.py, replay() versus main().
   replay(training_trial, trained_model) returned ordinary metrics (coverage
   0.2096128170894527) without an overlap warning. CLI correctly rejected the same
   kind of misuse. Direct library callers need an explicit check until shared
   evaluation validation is implemented. Replaying training data is useful for
   debugging but must not silently be represented as held-out evaluation.

D. Duration metrics omit the last rendered audio block.
   Location: src/nova2026/auditory/evaluation.py, selection_metrics(); caller in
   scripts/auditory/replay.py.
   The probe rendered 23.99225 seconds with known truth throughout, but reported
   23.968 known seconds, omitting 0.02425 seconds. np.diff(..., append=times[-1])
   assigns zero duration to the final block. Supply the actual interval end.

LIMITATIONS AND NEXT TESTS

  generated MATLAB fixture and mocked MNE CNT reader.
- No amplifier, microphone, sounddevice hardware, headphone timing, loopback,

  frequencies for the two sources. They establish software plumbing, not human
  accuracy or actual within-trial switching. Add balanced and switching fixtures.
